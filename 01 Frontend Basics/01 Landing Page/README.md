<img src="codestart-assets/icon-html.svg" alt="HTML icon">

Assets included:

- `logo.svg`: CodeStart logo
- `hero-illustration.svg`: hero section image
- `icon-html.svg`: HTML Structure feature icon
- `icon-css.svg`: CSS Styling feature icon
- `icon-responsive.svg`: Responsive Layout feature icon
- `about-illustration.svg`: about section image
- `icon-rocket.svg`: CTA icon
- `social-icons.svg`: footer social icons
