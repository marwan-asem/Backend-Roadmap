# Portfolio Landing Page Project

## What I Built

In this project, I built a simple personal portfolio landing page using HTML and CSS.

The page introduces me, shows my skills, displays simple project cards, and gives visitors a way to contact me.

## Page Sections

## 1. Header

The header is the top part of the page.

It contains:

- my logo
- navigation links

The navigation links help users move to different parts of the page:

- Home
- About
- Projects
- Contact

## 2. Hero Section

The hero section is the first big section visitors see.

It contains:

- main heading
- short introduction paragraph
- button to view my work
- avatar image

I used Flexbox to place the text beside the avatar image on large screens.

## 3. About Section

The About section tells visitors a short description about me.

It contains:

- profile icon
- section title
- small decorative line
- short paragraph

The small line is made with CSS instead of using an empty image.

## 4. Skills Section

The Skills section shows the technologies I am learning.

It contains cards for:

- HTML
- CSS
- JavaScript Basics

Each card has an icon and a title.

## 5. Projects Section

The Projects section shows examples of practice projects.

It contains project cards for:

- Profile Card
- Landing Page
- Portfolio Page

Each project card has:

- image preview
- project title
- short description
- button

## 6. Contact Section

The Contact section lets visitors contact me.

It contains:

- contact title
- short message
- email link
- send message button

The email uses `mailto:` so when users click it, their email app can open.

## 7. Footer

The footer is the bottom part of the page.

It contains:

- copyright text
- social links

## What I Practiced

In this project, I practiced:

- writing semantic HTML
- linking CSS to HTML
- using sections to organize a page
- using classes for styling
- using Flexbox for layout
- using CSS Grid for cards
- making buttons
- adding hover effects
- using images correctly
- writing `alt` text for images
- using CSS variables for colors
- making the page responsive with media queries

## Best Practice I Learned

A real website should use the full browser width.

The sections should be full width, and the content inside them should be centered using a `.container`.

Example:

```css
.container {
    max-width: 1120px;
    margin: 0 auto;
    padding: 0 32px;
}
```

This keeps the page professional because the background fills the screen, but the content stays readable.
